## Changes

- Added `normalizeStockLines`: validates positive safe-integer quantities, aggregates repeated `(variantId, warehouseId)` lines, rejects aggregate overflow and sorts targets deterministically.
- Applied normalization to reserve, commit and release. This keeps movement identity aligned with aggregate order quantities and prevents repeated order lines from being misread as duplicate idempotent operations or from under-reserving stock.
- Moved inventory audit writes into the same transaction as stock/movement changes for both self-owned and caller-supplied transactions. An audit persistence failure now aborts that inventory transaction rather than leaving an unaudited mutation; an outer rollback cannot leave a false audit record.
- Reordered validation so quantity shape is checked first, then an existing operation movement is validated for exact idempotent quantity, and only a new operation checks current availability/reservation. This allows an exact retry after stock was consumed/released while still rejecting conflicting reference reuse.
- No API route, DTO, schema, migration, inventory threshold, accounting policy, order lifecycle, provider, or security policy was changed.

## Discovery matrix

Map for every relevant route:
1. HTTP method/path and controller/owner;
2. @Public / auth guard / permission slug and required elevation for sensitive fields;
3. raw source data and explicit response serializer;
4. PII fields (customer identity/contact/address/document);
5. payment/provider secrets, JWT/session IDs, webhook raw payload, internal leases or tokens;
6. pagination bounds, filter/sort allowlisting, export size and rate/limit protections;
7. CSV/formula injection, spreadsheet encoding and document-safe export;
8. audit evidence for sensitive reads, exports and denied/allowed mutations;
9. request/correlation IDs, IP, user-agent trust and retention of sensitive values;
10. possible N+1, heavy unbounded queries and cross-tenant/scope leakage if product has tenant boundaries.

Record existing public responses and intentionally supported permissions; do not invent tenant separation or business entitlements.

## Mandatory invariants

- Unauthenticated -> 401; authenticated without exact permission -> 403.
- Roles and permissions are enforced server-side; no dev-admin bypass in production/staging.
- Basic customers.read masks sensitive identifiers; customers.read_sensitive controls unmasking, with audit evidence and minimal reveal.
- Customer exports are explicitly authorized and, if intentionally disabled by existing contract, remain disabled; never silently expose PII.
- Financial/payments reports cannot be opened with weaker unrelated permissions.
- Responses serialize only approved public fields; never raw database models, tokens, hashes, leases, encrypted payloads, credentials or webhook raw bodies.
- Sensitive field redaction applies in nested objects, errors, logs, audit and export results.
- Pagination and export work are bounded and deterministic; malformed filters reject.
- CSV/Excel output sanitizes formula injection (=, +, -, @, tabs, control chars) without altering business numeric totals; tests show expected value contract.
- Audit persistence is atomic with protected admin mutations where current transaction boundary requires it; read-only admin requests do not fabricate writes.
- Permission matrix and export safety do not regress checkout, event-bus or EX-05 auth/session behavior.
- Do not change public storefront response contracts or real-provider operation.

## Demonstrated defect and bounded change

The independent SALE challenger demonstrated a P2 using synthetic upstream fault injection on the compiled backend: the generic refresh BFF returned enriched private fields/arbitrary operational text and malformed successful JSON with HTTP 201. The current normal backend response contains no such private fields. This is a response-contract weakness, not evidence of a current production disclosure, a provider call or an RBAC bypass.

Only three exclusively assigned files change:

- `frontend/src/app/api/admin/payments/[id]/refresh-status/route.ts`: validate UUID and empty-object/bodyless request; retain the authenticated, origin-protected generic proxy; validate successful identity/status/provider response and project the authorized fields.
- `frontend/src/tests/ex08-sale-refresh-boundary.test.ts`: 26 new tests against the actual route and generic proxy. Only cookies/config and the upstream network are controlled test dependencies.
- This report. ROOT owns the subsequent USER_IMPACT_LOG entry, integration and STATE transition.

The successful response is restricted to `id`, an existing payment status, `refreshed: false`, and the existing `provider_not_configured` operational status/message. The response ID must equal the requested ID. Unexpected top-level personal/financial fields are removed. Malformed identity/status, `refreshed: true`, unknown operational flags, arbitrary/missing message or a contradictory provider state return HTTP 502 with a public `contract_error`. Existing upstream errors are returned after the original proxy's safe normalization. All responses retain `private, no-store`.

The canonical message is taken directly from the current controller: “No se consultó proveedor externo porque PSE no está configurado.” No new provider status, payment policy, approval, endpoint, permission or backend change was invented. A future configured-provider implementation must explicitly update and verify this contract; a new outcome cannot silently pass this blocked-provider boundary.
